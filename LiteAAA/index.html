How this is built



One small program. No cellular standard, no core network, no radio.
One network and three phones run on one machine and talk over UDP.



Run a device anywhere


On any computer with Python 3. Nothing to install.


curl -O https://zechengli.github.io/LiteAAA/device.py
python3 device.py dave


The device finds this network by itself and registers. Then use it here like the built-in phones:
status, idle, page dave, verify dave.
Its own window shows what it hears and what it answers.
