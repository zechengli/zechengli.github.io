Paging

APIWhat it does
statusshow the three phones
idlerelease all phones; every phone goes idle
page <phone>send the phone's identity to all phones; only that phone answers
lose <phone>take a phone out of coverage; it stops answering pages
find <phone>bring it back

Verification

APIWhat it does
verify <phone>page the phone, then the phone verifies the network and the network verifies the phone
key <phone> wronggive the network a wrong key for that phone, so verification fails
key <phone> realput the real key back

Nonce

APIWhat it does
nonce <number>enter the nonce after a verification has passed; one try

How this is built



One small program. No cellular standard, no core network, no radio.
One network and three phones run on one machine and talk over UDP.



Run a device anywhere


On any computer with Python 3. Nothing to install.


curl -O https://zechengli.github.io/LiteAAA/device.py
python3 device.py dave


The device finds this network by itself and registers. Then use it here like the built-in phones:
status, idle, page dave, verify dave.
Its own window shows what it hears and what it answers.
