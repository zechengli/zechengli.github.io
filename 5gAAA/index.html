Paging

APIWhat it does
statusshow the three phones
idlerelease all radio links; every phone goes idle
call <phone>send data to a phone; the network pages it if it is idle
use <phone>the phone sends data itself; it wakes up without a page
lose <phone>take a phone out of coverage; it stops answering pages
find <phone>bring it back; all phones end up idle
wireshow the last messages between core, cell and phones

Verification

APIWhat it does
verify <phone>page the phone, then the phone verifies the network and the network verifies the phone
key <phone> wronggive the network a wrong key for that phone, so verification fails
key <phone> realput the real key back

Nonce

APIWhat it does
nonce <number>enter the nonce after a verification has passed; one try

Projects



  
ProjectWhat it providesUsed here

  
Open5GSthe core network: AMF, AUSF, UDM, UDR, SMF, UPF, NRFyes

  
UERANSIMtwo programs: nr-gnb, a simulated cell, and nr-ue, a simulated phone with its SIMyes

  
srsRANa real cell and phone that drive radio hardwareno, only for the over-the-air version




Open5GS has no cell or phone of its own. It needs one in front of it: UERANSIM when simulating, srsRAN with a radio when on the air.
UERANSIM is a separate open-source project (github.com/aligungr/UERANSIM). It is not part of Open5GS or srsRAN.

Roles



  
RolePlayed byWhat it does here

  
Phone + SIMnr-ue (UERANSIM)Holds the key K. Sleeps when idle. Answers a page. Checks the network's AUTN. Computes RES*.

  
Cellnr-gnb (UERANSIM)Passes the page to the phones and relays everything else.

  
AMFOpen5GS, patchedKnows which phones are registered and idle. Sends the page. Runs the challenge. Does the first check of the answer.

  
AUSFOpen5GSDoes the final check of the phone's answer.

  
UDM + UDROpen5GS + MongoDBStores K for each SIM. Creates the challenge.

  
SMF + UPFOpen5GSCarry the data. The UPF holds a packet for an idle phone and reports it.

  
Bridgebridge.pyTurns an API call from this page into one script command.
